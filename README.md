# لاندات أزرق الأردن

| الرابط | السيجمنت | الإعلانات اللي بتودّي عليها |
|---|---|---|
| `/stores` | أصحاب المتاجر → إعلانات | إعلانات أصحاب المتاجر |
| `/shops` | محلات أزياء وعطور → متجر | سكريبتات 7، 8، 9، 22، 23، 24 · تصاميم 7، 8، 9 |
| `/influencers` | مطاعم، عيادات، صالونات → مشاهير | سكريبت 10 · تصميم 10 |
| `/start` | زيادة دخل → متجر من الصفر | سكريبتات 15، 27، 30 |

## قبل النشر
1. عبّي كل `class="todo"` (المربعات الصفرا المخططة) بأرقام وأسماء حقيقية.
2. لوجوهات العملاء: حطها بـ `assets/img/clients/` وبدّل `logo-slot`.
3. إعدادات عامة بـ `assets/js/main.js` أول الملف: رقم الواتساب، Pixel ID، رابط استقبال الليدز.

## روابط الإعلانات
حط UTM عشان تعرف أي إعلان جاب الليد (بتوصل مع رسالة الواتساب ومع الفورم):
`https://YOUR-DOMAIN/shops?utm_source=meta&utm_campaign=shops&utm_content=script7`

## الأحداث للبكسل
- `Lead` عند إرسال الفورم
- `Contact` عند الضغط على واتساب
- `CompleteRegistration` عند خلص اختبار الجاهزية (`/start`)
